# 📞 SIPSIM Analytics — Аналитика звонков GoTrips

Автоматическая система анализа телефонных звонков менеджеров туристической компании **GoTrips**.

Каждый день система забирает все звонки из IP-телефонии SIPSIM, транскрибирует их через **Deepgram** и анализирует через **Claude AI**. РОП получает в Telegram ежедневный отчёт + Excel-файл с транскриптами всех звонков. Каждый понедельник — недельный отчёт с рейтингом менеджеров.

---

## Что умеет система

### По каждому звонку
- Транскрипт с разметкой по спикерам (`Менеджер` / `Клиент`) и тайм-кодами
- **Оценка качества продажи 1–5** (AI)
- **Исход звонка**: бронь / интерес / перезвон / информация / отказ / жалоба
- **Направление тура**: Питер, Карелия, Дагестан, Мурманск и т.д.
- **Проблемы**: не взял контакт, не предложил альтернативу, грубость и др.
- **Возражения клиента** и как менеджер их обработал

### Ежедневный отчёт в Telegram (07:30)
- Общая сводка: всего / отвечено / пропущено / ср. длительность / ср. ожидание
- Статистика по каждому менеджеру: звонки, скорость ответа, оценка, исходы, проблемы
- Топ направлений туров по обращениям
- AI-вывод для РОПа с конкретными действиями
- **Excel-файл** со всеми звонками: проблемные наверху, полный транскрипт в последнем столбце

### Еженедельный отчёт в Telegram (понедельник, 08:00)
- Агрегат за 7 дней
- Рейтинг менеджеров по качеству и объёму
- Недельный спрос по направлениям туров
- Глубокий AI-анализ для РОПа: кому помочь, что улучшить, план на неделю

## Архитектура

```
sipsim_analytics/
├── scripts/
│   ├── fetch_calls.py       # Забирает CDR из SIPSIM API
│   ├── transcribe.py        # Транскрибирует через Deepgram nova-2 (ru)
│   ├── analyze_calls.py     # AI-анализ каждого звонка через Claude
│   ├── manager_stats.py     # Агрегация статистики по менеджерам
│   ├── direction_stats.py   # Спрос по направлениям туров
│   ├── export_excel.py      # Excel с транскриптами для РОПа
│   ├── send_telegram.py     # Отправка в Telegram
│   ├── run_daily.py         # Ежедневный пайплайн
│   └── run_weekly.py        # Еженедельный отчёт
├── data/
│   ├── calls/               # CDR JSON по датам (YYYY-MM-DD.json)
│   ├── transcripts/         # Транскрипты по public_id
│   ├── analysis/            # AI-анализ по public_id
│   ├── reports/             # Excel-файлы отчётов
│   ├── phones_cache.json    # Кэш справочника телефонов
│   └── managers.json        # Маппинг номер → имя менеджера
└── .env                     # Секреты (не в репозитории)
```

### Пайплайн

```
SIPSIM API /calls
      ↓
  fetch_calls.py  →  data/calls/YYYY-MM-DD.json
      ↓
  transcribe.py   →  data/transcripts/{public_id}.json
  (Deepgram nova-2, ru, diarize)
      ↓
  analyze_calls.py  →  data/analysis/{public_id}.json
  (Claude AI: score, outcome, direction, issues)
      ↓
  run_daily.py
  ├── manager_stats.py   → блок по менеджерам
  ├── direction_stats.py → блок по направлениям
  ├── export_excel.py    → calls_YYYY-MM-DD.xlsx
  └── send_telegram.py   → текст + Excel в Telegram
```

## Установка

### 1. Зависимости
```bash
pip3 install deepgram-sdk anthropic python-dotenv requests openpyxl --break-system-packages
```

### 2. Файл `.env`
```env
SIPSIM_TOKEN=ваш_токен_из_личного_кабинета_sipsim
DEEPGRAM_API_KEY=ваш_ключ_deepgram
TELEGRAM_BOT_TOKEN=токен_бота
TELEGRAM_CHAT_ID=id_чата

> SIPSIM токен: Личный кабинет → Интеграции → API → Подключить

  "+375441234567": "Иванова Мария",
  "+375441234568": "Петрова Анна",
  ...
}
```

### 4. Cron
```bash
crontab -e
```
```

30 7 * * * /usr/bin/python3 /path/to/sipsim_analytics/scripts/run_daily.py >> /path/to/sipsim_analytics/data/cron_daily.log 2>&1

```

## Excel-отчёт для РОПа

Каждый день к тексту в Telegram прикрепляется Excel-файл `calls_YYYY-MM-DD.xlsx`:

| Столбец | Содержимое |
|---------|-----------|
| Время | Время звонка |
| Менеджер | Имя менеджера |
| Тип | Входящий / Исходящий |
| Статус | Отвечен / Не отвечен / Занято |
| Клиент | Номер телефона клиента |
| Длит. | Длительность разговора |
| Ожидание | Время до ответа |
| **Оценка AI** | **1–5, цветовая маркировка** |
| Исход | Бронь / Интерес / Перезвон и т.д. |
| Направление | Название тура/направления |
| **Проблемы** | Список выявленных AI проблем |
| Возражения | Что говорил клиент против |
| Оценка менеджера | Развёрнутый комментарий AI |
| **Транскрипт** | **Полный текст с тайм-кодами** |

Проблемные звонки (оценка ≤3) сортируются наверх и выделяются цветом.

### Критерии оценки AI
| Оценка | Значение |
|--------|---------|
| 🔴 1 | Грубость, игнор вопросов, потерял клиента |
| 🟠 2 | Формально ответил, без вовлечения |
| 🟡 3 | Норма: ответил на вопросы |
| 🟢 4 | Хорошо: выявил потребности, предложил варианты |
| 💚 5 | Отлично: выявил потребности, обработал возражения, договорился о следующем шаге |

## Рейтинг менеджеров — 100-балльная система

Еженедельный отчёт содержит **персональный скоринг каждого менеджера**. Это объективная оценка работы за неделю, которая помогает РОПу сразу видеть лидера и тех, кому нужна поддержка.

### Из чего складывается рейтинг

```
Итог = Качество (70) + Доступность (15) + Скорость ответа (15)
```

Средняя длительность разговора по каждому менеджеру **отображается в отчёте**, но в баллы не входит — слишком короткие звонки могут быть вполне корректными (ошибочный номер, быстрый вопрос от действующего клиента, уточнение по сервису). РОП смотрит на длительность как контекст, а не как показатель качества.

---

#### 1. Качество разговора — 70 баллов (главный критерий)

Claude прослушивает каждый звонок и ставит оценку **1–5**. Средняя оценка за неделю умножается на 14.

| Средняя оценка | Баллы | Что это значит |
|:---:|:---:|---|
| 5.0 | 70 | Каждый звонок — образцовый |
| 4.5 | 63 | Отличная работа |
| 4.0 | 56 | Хороший уровень |
| 3.5 | 49 | Есть куда расти |
| 3.0 | 42 | Ответы формальные, без вовлечения |
| 2.0 | 28 | Серьёзные проблемы с качеством |

**На что влияет оценка AI:**
- Выявил ли менеджер потребность клиента или просто ответил на вопрос?
- Предложил ли конкретные варианты туров?
- Договорился ли о следующем шаге (бронь, перезвон, встреча)?
- Обработал ли возражения или сразу отпустил клиента?

> 💡 **Фокус для менеджера:** задавать уточняющие вопросы, предлагать варианты, всегда завершать звонок конкретным договором о следующем шаге.

---

#### 2. Доступность (ответы на звонки) — 15 баллов

```
(количество отвеченных / всего звонков) × 15
```

Каждый пропущенный звонок — потерянный клиент и прямой штраф в рейтинге.

| Ответы | Баллы |
|:---:|:---:|
| 100% | 15 |
| 93% | 14 |
| 80% | 12 |
| 67% | 10 |

> 💡 **Фокус для менеджера:** не оставлять телефон без присмотра, перезванивать по пропущенным сразу после освобождения.

---

#### 3. Скорость ответа — 15 баллов

Среднее время от звонка до поднятия трубки по всем отвеченным звонкам.

| Ожидание клиента | Баллы |
|---|:---:|
| до 15 секунд | 15 |
| 16–25 секунд | 12 |
| 26–35 секунд | 9 |
| 36–50 секунд | 6 |
| больше 50 секунд | 3 |

> 💡 **Фокус для менеджера:** чем дольше клиент ждёт ответа, тем ниже его настрой к покупке. Первые 15 секунд — золотое время.

---

#### Средняя длительность разговора — информационный показатель (в баллы не входит)

Отображается в отчёте по каждому менеджеру. РОП использует как сигнал для анализа, а не как механический штраф.

**Что длительность говорит РОПу:**
- Менеджер с высокой средней длительностью + низкой конверсией → возможно, затягивает диалог без движения к цели, «болтает» вместо продажи
- Менеджер с высокой длительностью + высоким качеством (score 4–5) → ведёт глубокие переговоры, это норма для сложных продаж
- Менеджер с короткими звонками → может быть как быстрым и точным, так и поверхностным — смотреть на score AI

> 💡 **Фокус для менеджера:** длинный разговор сам по себе не проблема. Проблема — когда много времени потрачено, а результата нет. Цель каждого звонка — конкретный следующий шаг.

---

### Итоговая шкала

| Баллы | Уровень | Значение |
|:---:|---|---|
| 80–100 | 🟢 Хорошо | Менеджер работает на высоком уровне |
| 60–79 | 🟡 Удовлетворительно | Есть точки роста, нужен анализ |
| менее 60 | 🔴 Требует внимания | Нужна работа с РОПом |

### Важные правила оценки

- Звонок, где клиент сам сказал «занят, перезвоните» — **не штрафует** менеджера
- Ошибочный номер, обработанный вежливо — **не штрафует** менеджера
- B2B/партнёрские звонки с профессиональными ответами — оценка **не ниже 4**
- Короткий звонок, где клиент получил точный ответ на конкретный вопрос — оценка **не ниже 4**
